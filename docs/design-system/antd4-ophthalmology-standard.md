# 眼科专科系统 Ant Design 4.x 原型规范

## 适用范围

本规范适用于眼科专科系统现有高保真原型的迭代，以及后续新增功能模块。HIHIS 顶部功能标签页、左侧功能菜单和患者上下文结构保留；页面级控件、数据展示和反馈组件统一采用 Ant Design 4.x 视觉与交互模式。

## 实施原则

1. 优先复用 `app/antd4-baseline.css` 中的公共变量和组件状态，不在模块内重新定义主色、圆角、字号和控件高度。
2. 原型可使用语义等价的 HTML/CSS 实现，不要求为展示目的强制引入 AntD 运行时依赖；进入研发实施时使用 Ant Design 4.x 对应组件。
3. 业务效率优先。高频门诊操作允许平铺选择和紧凑表格，但控件状态与视觉仍遵守 AntD 4.x。
4. 页面结构遵循“页面标题—查询区—内容卡片/表格—操作反馈”；关联配置紧邻触发字段。

## 基础令牌

| 类别 | 标准 |
| --- | --- |
| 主色 | `#1890FF`；悬停 `#40A9FF`；按下 `#096DD9` |
| 页面背景 | `#F0F2F5` |
| 卡片背景 | `#FFFFFF` |
| 标题文字 | `rgba(0,0,0,.85)` |
| 正文文字 | `rgba(0,0,0,.65)` |
| 次要文字 | `rgba(0,0,0,.45)` |
| 边框 | `#D9D9D9`；弱分割线 `#F0F0F0` |
| 正文字号 | `14px / 22px` |
| 页面标题 | `20px / 28px`，字重 500～600 |
| 控件高度 | 默认 32px；紧凑 24px；大号 40px |
| 圆角 | 默认 2px |
| 间距 | 4px 基数，常用 8/12/16/24/32px |

## 组件映射

| 原型场景 | AntD 4.x 对应组件 | 统一要求 |
| --- | --- | --- |
| 查询条件 | Form、Input、Select、DatePicker、Radio.Group | 标签明确，默认控件高 32px；查询按钮使用主按钮 |
| 列表 | Table、Pagination、Empty | 表头 `#FAFAFA`；操作列使用文字按钮；空态统一 |
| 状态 | Tag、Badge | 仅状态和来源使用色彩，普通文本不滥用标签 |
| 页面切换 | Tabs | 当前项主色文字和 2px 下划线 |
| 新增/编辑 | Drawer | 右侧抽屉；头、体、底固定分区；主按钮放右侧 |
| 确认/选择 | Modal | 标准遮罩与阴影；危险操作需二次确认 |
| 反馈 | Message、Notification、Alert | 成功、警告、错误使用 AntD 语义色 |
| 多选 | Checkbox、Select mode=multiple、TreeSelect | 高频少量选项可平铺，多量选项使用搜索弹层 |

## 页面验收

- 同一层级的按钮、输入框、表格和弹窗视觉一致。
- 每个交互控件包含默认、悬停、聚焦、按下、禁用状态。
- 不再出现模块自定义主色、超大圆角、无意义渐变或不一致阴影。
- 高频流程尽量少一步操作，同时维持清晰的选中与反馈状态。
- 新模块合并前对照本规范与公司 UI 规范完成浏览器验收。
