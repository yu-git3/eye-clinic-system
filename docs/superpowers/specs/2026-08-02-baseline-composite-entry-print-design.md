# OK镜基线组合录入与固定版式打印设计

## 1. 目标与范围

完善角膜接触镜基础档案的基线评估交互，使检查模板既保持结构化指标存储，又符合医生按临床表达快速录入、查看和打印的习惯。本轮包含基线检查录入和固定版式打印预览，不包含试戴、品牌参数、定片、交付及复查。

## 2. 指标来源调整

- 睑裂高度、眼睑张力归入“角膜地形图”检查组件，数据来源为医技检查。
- 接口返回结构化指标时自动获取；PACS 仅返回 PDF/图片时，医生查看原始报告后补录。
- 医技检查自动值经医生修改时，保留接口原值、修订值、修订人及修订时间。
- “眼健康检查”不再重复维护睑裂高度、眼睑张力，只保留医生查体的正常/异常检查项目。

## 3. 结构化存储与组合展示

所有指标继续独立存储和维护外部映射。检查模板可定义“组合录入行”，用于把相关指标放在同一行展示；组合行不产生新的合并指标。

### 3.1 角膜地形图

每只眼一行，依次录入：Ks曲率、Ks轴位、MinK曲率、MinK轴位。页面实时生成：

- `OD：Ks 43.83D@83°；MinK 42.79D@179°`
- `OS：Ks 43.60D@159°；MinK 43.10D@63°`

睑裂高度和眼睑张力在同一检查组件内作为独立行展示。第一版不增加 K2、ΔK、E。

### 3.2 医学验光

散瞳、小瞳分别作为检查组件。每只眼一行组合录入球镜、柱镜、轴位、矫正视力，棱镜为选填；各字段仍独立存储。

### 3.3 眼表综合报告

每只眼一行组合录入 NIBUT First、NIBUT Average、TMH，各字段分别保存并显示参考范围。

## 4. 共享眼健康检查

- 基线模板自动加载眼健康检查，不显示“使用检查组件录入”入口。
- 基线与专科病历复用同一个检查实例和同一套交互组件。
- 支持双眼/单眼全部正常、OD与OS互相复制、正常/异常切换、异常枚举和补充描述。
- 自动生成门诊病历“专科查体”描述；基线完成时同时保存检查结果快照。

## 5. 基线页面交互

- 建档后自动加载9组检查组件。
- 眼健康检查默认展开；其他已获取检查可折叠展示，待补录或异常组件优先展开。
- 通用数值检查使用OD/OS表格；存在临床组合表达的检查使用组合录入行。
- 每个医技检查组件显示数据来源、获取状态、原始报告入口、原值及修订痕迹。
- 完成基线前校验必填健康背景、必需检查和医生评估；暂存允许未完成。

## 6. 固定版式打印预览

- 基线页提供“打印预览”按钮。
- 第一版严格按照南医现用《角膜接触镜档案》固定版式及固定分页生成，不随网页布局自由流式分页。
- 打印内容包含患者信息、健康与戴镜背景、全部基线检查结果、组合后的临床摘要、医生评估、检查/建档日期、医生签名区域。
- 无值字段保留固定位置并显示空白；内容过长按版式限定区域换行或续页，不压缩字号破坏固定格式。
- 打印取已保存的基线快照；未保存修改进入预览时提示先暂存。
- 原始PACS报告不嵌入档案正文，只作为系统内关联附件查看。

## 7. 数据与版本规则

- 保存基线模板版本、检查模板版本、指标版本、结构化值、组合摘要及原始报告关联快照。
- 后续模板升级不追改历史档案和历史打印件。
- 治疗方式变更保留原基线快照；是否补充或重新评估由变更策略决定。

## 8. 验收标准

1. 基线与专科病历中的眼健康检查交互完全一致，并复用同一实例。
2. 睑裂高度、眼睑张力只在角膜地形图组件中出现，来源显示医技检查。
3. 角膜地形图、散瞳验光、小瞳验光、眼表综合报告均按组合行录入，但指标可分别读取和保存。
4. 角膜地形图摘要严格输出 Ks 与 MinK 的曲率和轴位。
5. 打印预览符合南医固定版式与固定分页，且使用已保存快照。
6. 接口值被修改时可查看原值和修订记录。
