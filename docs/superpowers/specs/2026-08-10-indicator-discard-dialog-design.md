# 临床指标抽屉确认框与文本型长度规则设计

## 问题

临床指标新增/编辑抽屉存在未保存内容时，关闭操作会显示二次确认框。当前确认框按模块内部区域定位，视觉上卡在主内容与抽屉边界附近，不符合全局模态框的定位和层级预期。

## 确认方案

采用全局模态确认方式：

1. 确认框相对浏览器可视窗口水平、垂直居中，不受主工作区、侧栏或抽屉宽度影响。
2. 二次遮罩覆盖整个浏览器可视窗口，层级高于抽屉及抽屉原遮罩。
3. 确认框位于二次遮罩之上；抽屉保持打开，但处于变暗、不可操作状态。
4. 点击“继续编辑”只关闭确认框，保留抽屉及当前未保存内容，并恢复抽屉操作。
5. 点击“放弃修改”关闭确认框和抽屉，丢弃本次未保存内容。
6. 点击二次遮罩不关闭确认框，防止误触导致状态不明确。
7. 按 `Esc` 等同点击“继续编辑”。
8. 确认框打开后，键盘焦点进入确认框；关闭后焦点返回抽屉关闭按钮。

## 实现边界

- 调整临床指标新增/编辑抽屉的未保存退出确认交互。
- 文本型最大长度允许范围统一为 `1～200`，默认值统一为 `50`。
- 不增加“文本结果默认值”字段；临床结果必须由来源数据或用户录入产生。
- 超过配置范围时阻止保存，并提示“最大长度须为1至200”。
- 同步更新原型、校验测试和临床指标定义 PRD。
- 沿用现有 Ant Design 4.x 视觉变量和按钮语义。
- 不改变列表中的启用/停用确认框业务逻辑；公共层级样式如需复用，必须保证该确认框不回归。

## 验收标准

1. 无论抽屉宽度和浏览器尺寸如何，确认框中心点与浏览器可视窗口中心一致。
2. 确认框完整显示在抽屉上方，抽屉及主页面均不能被点击。
3. “继续编辑”、`Esc` 均保留未保存内容。
4. “放弃修改”关闭抽屉，再次新增时使用新的空白表单。
5. 遮罩点击不会关闭确认框或抽屉。
6. 选择文本型时最大长度自动填入 `50`；可维护 `1～200`，输入 `0` 或 `201` 时不能保存。
7. 原型页面与临床指标定义 PRD 对文本型长度规则的描述一致。
8. 页面测试、生产构建和浏览器实际操作均通过。
